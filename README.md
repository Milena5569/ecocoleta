# EcoColeta

Sistema web para registrar e acompanhar coletas de resíduos de clientes fictícios. O projeto substitui o controle em planilha por uma aplicação com cadastro, consulta, edição, exclusão e painel de indicadores.

> Todos os dados usados no projeto são fictícios. Não são utilizados nomes, CNPJs ou endereços de empresas reais.

## Tecnologias

- HTML, CSS e JavaScript
- Node.js e Express
- MySQL
- `mysql2` para conectar a API ao banco
- `dotenv` para carregar variáveis de ambiente
- `cors` para permitir a comunicação entre o front-end e a API

## Requisitos

- Node.js e npm
- MySQL Server 8 ou compatível
- MySQL Workbench ou outro cliente SQL
- Visual Studio Code
- Git
